3. **QA_OWNER (T01/T02) independent gate:** verify non-draft, current-base/merge-ref integration, no overlap, actual RED/GREEN, tests and current artifact hashes. 4. **Human gate:** T01/T02 **during their own scheduled QA checks** reports meaningful PASS/FAIL/NOT RUN, downloadable 9:16 and 16:9 if actually produced or honestly `REUSED`/`NO BUILD`, 3–6 concrete manual actions and feedback instructions. Creator logs `PR, video hash, device, aspect, timestamp, expected/actual, screenshot` to chat/[#36](https://github.com/qualife1291/Auto-Tool-Video/issues/36). BA01 records approvals and release decision only with evidence.
