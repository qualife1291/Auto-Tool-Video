## Required workflow and evidence

1. **BA01 assign** unique ID, issue, specification/AC, priority, exclusive source/test paths, dependencies and expected output. Coder comments **CLAIM C01/C02/C03/C04** with base SHA, branch, paths, exact status and conflict scan. One file writer at a time.
2. **Coder RED→GREEN** actual old-code failing runtime test, minimally scoped implementation, fixed-head focused plus full Ruff/format/mypy/pytest, Vitest/TS/build/Prettier, Playwright, dual-aspect native 1080p FFprobe/full decode if in scope. Document success/failure/skips and exact SHA. Keep sources/providers FREE-first and rights-safe.
3. **T01 independent gate:** verify non-draft, current-base/merge-ref integration, no overlap, actual RED/GREEN, tests and current artifact hashes. If FAIL or NOT RUN, leave PR unmerged, comment repro and assign back via BA01 ownership. If PASS, user authorizes T01 to **merge using exact expected HEAD SHA** into canonical; recheck merged SHA + CI and report BA Epic #26. `QA-PASS-CODE` ≠ `FEATURE-DONE-VERIFIED`.
4. **Human gate:** T01 **each hour** reports meaningful PASS/FAIL/NOT RUN, downloadable 9:16 and 16:9 if actually produced or honestly `REUSED`/`NO BUILD`, 3–6 concrete manual actions and feedback instructions. Creator logs `PR, video hash, device, aspect, timestamp, expected/actual, screenshot` to chat/[#36](https://github.com/qualife1291/Auto-Tool-Video/issues/36). BA01 records approvals and release decision only with evidence.
5. **Timing & quality:** 30fps CFR, portrait 1080×1920/landscape 1920×1080, H.264 yuv420p, AAC48k, full decoded frames/PTS, total ≤1800 frame-aligned frames / 60s; scene ≤20s; finished voiced MP4 −17 to −15 LUFS, true peak ≤−1 dBTP; Unicode/safe zones/continuity/speech and science need manual review.
6. **Monitoring without Actions flood:** GitHub T01 watcher [PR #43](https://github.com/qualife1291/Auto-Tool-Video/pull/43) now **only** cron `7,22,37,52 * * * *` UTC + manual dispatch; **do not reinstate `workflow_run.completed`** broadly. ChatGPT T01 sends mandatory manual QA report **hourly**. The workflow is not a substitute for creator signoff.

**Status vocabulary:** `ASSIGNED → CLAIMED → DEV-READY → QA-PASS-CODE → CODE-MERGED → MERGED-SHA-QA-PASS → CREATOR-APPROVED → FEATURE-DONE-VERIFIED → RELEASE-APPROVED`. `NOT RUN`, `SKIPPED`, `BLOCKED`, `FAIL` are not PASS; each claim must link a run/artifact and exact SHA.
